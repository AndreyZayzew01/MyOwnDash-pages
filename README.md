# MyOwnDash

Личная доска задач на русском языке — пять столбцов, описания, чек-листы, сроки, приоритеты, цветные теги, архив и повторяющиеся задачи.

**Открыть сайт:** https://AndreyZayzew01.github.io/MyOwnDash-pages/

При первом открытии доска пустая. Можно создать свои задачи и теги. Изменения автоматически сохраняются в localStorage текущего браузера, остаются после обновления страницы и не видны другим посетителям. Между браузерами и устройствами синхронизации нет.

Для резервных копий и переноса используйте «Экспорт» и «Импорт». Импорт заменяет текущую доску; перед ним сохраните резервную копию. Очистка данных сайта удаляет сохранённую в браузере доску.

Сайт работает без отдельного сервера и регистрации. В этом репозитории находятся только готовые файлы веб-версии для GitHub Pages. Личные задачи владельца в публикацию не входят.
